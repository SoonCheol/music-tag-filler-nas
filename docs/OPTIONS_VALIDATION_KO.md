# 저장 옵션 검증 — 2026-10-21

## 발견 및 수정

1. 후보 선택 당시 빈 태그 보호가 초안 자체에 적용되어, 이후 옵션을 꺼도 후보값을 복구할 수 없었다. 후보값은 보존하고 체크/빈 태그 보호는 최종 미리보기·저장에 적용하도록 수정했다.
2. 커버 최대 크기는 옵션 기억을 해야만 서버 저장 설정에 반영됐다. 이번 저장 요청에 검증된 크기를 전달한다. 생략하는 기존 클라이언트는 이전 설정을 따른다.
3. 일반 재검색이 화면의 국가 대신 서버 기본값을 사용했다. 국가를 요청에 전달하며 @JP 등 명시적 접두사는 우선한다.
4. 후보 선택 후 가수 표기 옵션 변경은 재반영되지 않았다. 직접 편집한 필드는 보존하면서 후보에서 유래한 가수/앨범 가수만 갱신한다.
