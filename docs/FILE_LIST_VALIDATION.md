## 변경 범위

- 517px 고정 박스와 헤더를 유지하고 13행을 균등 배치합니다. 부족한 행은 조작 요소 없는 빈 행이며 초과분은 내부 스크롤로 탐색합니다.
- 전체 1400px 최대 폭을 유지하고 넓은 화면에서 파일 목록에 46%를 배정합니다. 양쪽 520px 최소 너비와 좁은 화면의 단일 열 배치를 사용합니다.
- 재생 / 저장된 커버 / 저장된 가사 L / 파일명 순서입니다. 아이콘은 24px, 간격은 4px입니다.
- 태그 읽기에서 얻은 has_cover·has_lyrics를 재사용합니다. 원본 가사 본문은 목록 응답에서 제외하며 이전 작업 기록도 응답할 때만 요약합니다. 가사 보기는 명시적인 클릭으로 본문을 가져옵니다.
- 화면 내부 IntersectionObserver(rootMargin=0)가 썸네일 요청을 시작합니다. 서버는 24px 이미지 256개를 파일별로 캐시하고 stat 변경 시 해당 항목만 교체합니다. 브라우저는 파일 리비전이 포함된 URL을 재사용합니다.
- 행 노드를 경로별로 재사용하고 내용이 바뀐 행만 갱신합니다. 스캔 검색·병렬성·저장 보호 로직은 변경하지 않습니다.
